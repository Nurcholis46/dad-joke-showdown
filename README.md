Entry for [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) on [make.fun](https://make.fun): one dad joke of at most 200 characters, written by a program (`main.ts`, Node 22) to `/output/entry.txt`.

The joke: "I named my dog Five Miles so I can tell people I walk Five Miles every day." (75 characters.) A father tells it at the table; the pun — walking Five Miles — lands on the first read, and the punchline arrives at the end.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
